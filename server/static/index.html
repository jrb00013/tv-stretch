API & credentials

Authenticated calls use the X-Control-Token header (same token as WebSocket query).

Quick bootstrap

Creates a home + rooms in one shot (no auth). Copies IDs into the form.

Rooms & handoff (REST)

No session loaded

Node health

ESP nodes registered for this home (last seen / firmware).

Diagnostics

Server-wide counts + WebSocket hub snapshot; “live” uses the home UUID field.

Spatial maps & occupancy

Feed SLAM / optical localization into the coordinator: store map JSON, then report room_id + confidence. Handoff runs when confidence ≥ server threshold (TV_STRETCH_PRESENCE_HANDOFF_MIN_CONFIDENCE).

Device simulator · /ws/device

Mimics an ESP32 node: uses the same WS host as the app channel. Auth via query ?home_id=&token= (node api_key) so browsers work without custom headers.

WebSocket · /ws/app

Browsers cannot set Authorization on WebSockets reliably — auth is passed as query params (token is masked in the log).

Log

Timestamped session transcript. Export for bug reports.
