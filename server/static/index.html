Spatial maps & occupancy

CLI recipes 
# Replace BASE and TOKEN (same as UI). Room UUID from GET /rooms.

curl -sS "$BASE/health/ready"
curl -sS -H "X-Control-Token: $TOKEN" "$BASE/spatial/maps"
curl -sS -X POST -H "Content-Type: application/json" -H "X-Control-Token: $TOKEN" \
  -d '{"label":"floor1","schema_version":"slam.v1","payload":{"rooms":[]}}' \
  "$BASE/spatial/maps"
curl -sS -X POST -H "Content-Type: application/json" -H "X-Control-Token: $TOKEN" \
  -d '{"room_id":"ROOM_UUID","confidence":0.9,"source":"cli","standby_others":true}' \
  "$BASE/presence/occupancy"

Device simulator · /ws/device

Mimics an ESP32 node: uses the same WS host as the app channel. Auth via query ?home_id=&token= (node api_key) so browsers work without custom headers.

WebSocket · /ws/app

Browsers cannot set Authorization on WebSockets reliably — auth is passed as query params (token is masked in the log).
